## 4. 复核与修复

复核按安全边界、状态一致性、迁移可逆性、功能开关、测试证据和文档链接逐项执行。

发现并修复两项非产品缺陷：

1. 初版 Vue Router 同一路由同时携带组件和可选重定向，不满足严格类型；已改成两个互斥的
   `RouteRecordRaw` 分支，类型检查和单元测试通过。
2. 首次把 ESLint 与 Playwright 并行运行时，Playwright 重建 `test-results` 目录导致 ESLint
   瞬时 `ENOENT`；已按串行门禁复跑全部通过。CI 在目录忽略策略完善前不得并行执行这两项。

复核未发现阶段 0 新增的 P0/P1 缺陷。

## 5. 已知风险与下一阶段约束

- 当前方向分析仍有 STEP04 使用 STEP01 Prompt、确认后重新生成导致漂移的问题。
- 当前模型调用 ID 在调用后随机生成，缺少可关联的完整调用日志。
- 当前租约无执行令牌、心跳和 fencing；不能证明多 Worker 安全。
- 当前医院关系虽无现存错挂，但数据库组合外键尚未补齐。
- V2 页面只是受控占位，不读取或推导课题状态；真实纵向切片在阶段 2 实现。
- 主 JS chunk 仍超过 500 kB，属于后续性能治理。

P0-A 必须先停止旧 Worker 再执行新增迁移，禁止新旧 Worker 混跑；一个现存
`WAITING_CONFIRMATION` 任务须在迁移后做兼容读取抽查。
