# 阶段 0：分阶段实施与追踪清单

- 目标：达到匿名医疗科研试点技术就绪
- 执行策略：全部采用 V1.2 推荐默认值
- 工作方式：每阶段检查 → 实现 → 测试 → 独立复核 → 修复/复测 → 门禁
- 当前状态：阶段 0、P0-A、P0-B、第二、第三阶段已通过，第四阶段正在核验

## 状态定义

- `TODO`：未开始；
- `DOING`：正在实施；
- `REVIEW`：实现完成，等待复核/门禁；
- `PASS`：证据完整且无 P0/P1；
- `BLOCKED`：存在明确阻断项。
