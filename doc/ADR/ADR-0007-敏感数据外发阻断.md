# ADR-0007：敏感数据外发默认阻断

- 状态：已接受
- 日期：2026-07-26

## 决策

上传内容依次经过类型/大小/MIME/魔数检查、恶意文件扫描接口、文本提取和敏感内容检测。高风险内容可按权限保存在医院项目内，但状态为 `BLOCKED_FOR_EXTERNAL_MODEL` 或 `REQUIRES_ADMIN_REVIEW` 时不得发送外部模型。

所有直接输入和上传提取内容最终都必须在外部模型适配器的出站调用点经过同一个
`ExternalModelInputGuard`，不能依赖某个上游页面、Controller 或文件流程已检查。该门禁同时
执行长度、直接标识和 Prompt Injection 规则；失败时只返回规则码且不得发起网络请求。

系统 Prompt 明确把用户研究想法视为不可信数据，禁止其中的角色覆盖、系统提示泄露、密钥
读取和工具/命令执行要求。结构化输出验证属于下游完整性控制，不能替代出站前的隐私阻断。

## 明确禁止

第一版不提供“用户忽略风险并继续外发”功能。

管理员、医生或配置项均不能绕过最终出站门禁；若未来确需例外，必须新建单独 ADR、医院数据
政策审批和可审计的最小范围机制。
