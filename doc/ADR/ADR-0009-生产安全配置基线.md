# ADR-0009：生产安全配置必须失败关闭

- 状态：已接受
- 日期：2026-07-29

## 背景

本地开发需要在 HTTP 下使用会话 Cookie，并需要匿名访问 Swagger/OpenAPI；这些便利不能
通过共享默认配置静默进入医院生产环境。

## 决策

生产部署必须同时启用持久化 profile 和安全叠加 profile：
`SPRING_PROFILES_ACTIVE=postgres,prod`。

`prod` profile 强制：

- 会话 Cookie 始终包含 `Secure`，即使外部配置错误地提供 `false`；
- Springdoc API 文档和 Swagger UI 默认关闭；
- 即使 Springdoc 被外部配置重新启用，安全过滤链也不会匿名放行文档路由；
- 文件扫描默认使用 `clamav`，扫描服务不可用时文件入库失败关闭。

本地 `memory` 或 `postgres` 开发 profile 保留 HTTP 和开发文档兼容性。生产入口仍必须由
HTTPS/HSTS 反向代理保护。

## 验证

`ProductionSecurityConfigurationTest` 在 `memory,prod` 下故意覆盖为不安全值，确认登录
Cookie 仍包含 `Secure`，`/v3/api-docs` 和 `/swagger-ui.html` 均返回 403，并确认文件扫描
配置为 `clamav`；原本地 HTTP/OpenAPI 测试继续通过。
