# ADR-0004：Agent 任务分步骤持久化

- 状态：已接受
- 日期：2026-07-26

## 决策

Agent 采用 18 个版本化步骤，每步保存输入、输出、Schema 版本、尝试次数、模型/Prompt/工具调用、错误、时间和人工确认。SSE 只是通知通道，数据库是事实源。

## 原因

支持幂等、重试、取消、超时、重启恢复、人工确认和审计，避免一次模型调用完成全部流程。

## 已落地

- Flyway V6 增加任务运行字段和 `ai_agent_event` 事件表。
- `memory` 与 `postgres` 提供同一仓储边界；正式运行以 PostgreSQL 为事实源。
- Worker 通过版本号和任务租约抢占，应用重启后可重新领取租约过期任务。
- 首批实现步骤 01～06，步骤记录包含输入/输出、Schema、尝试次数、Mock 模型调用标识、
  Prompt 版本、工具调用、错误、时间和人工确认。
- SSE 使用数据库事件 ID，支持浏览器通过 `Last-Event-ID` 补发；关闭浏览器不影响 Worker。
