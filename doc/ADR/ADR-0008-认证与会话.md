# ADR-0008：自建账号与不透明会话 Cookie

- 状态：已接受
- 日期：2026-07-26

## 决策

第一版使用医院代码、用户名和密码登录。密码使用 BCrypt 强哈希；浏览器只持有不透明会话令牌，服务端仅保存令牌 SHA-256 哈希。Cookie 使用 HttpOnly、SameSite=Strict，生产环境强制 Secure。

写接口启用 CSRF 校验。首次登录必须修改初始密码，修改密码或禁用账号后撤销既有会话。连续五次失败锁定十五分钟。

## 多医院边界

普通用户的医院只能由已认证会话取得。登录时医院代码仅用于定位账号；课题 API 不接受 `hospital_id`。平台管理员显式跨院管理必须记录审计。
